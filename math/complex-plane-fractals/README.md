# Complex Plane: фракталы и конформные отображения

Проект собран из двух учебных работ по теории функций комплексного переменного и доведён до состояния, в котором его можно запускать, проверять и показывать. Первая часть про итерации на комплексной плоскости: множества Мандельброта и Жюлиа, бассейны Ньютона и десятки способов их раскрасить. Вторая про конформные отображения: область с разрезом переводится в круговую и полосу цепочкой элементарных шагов, и каждый шаг можно увидеть.

Главная идея: всё считается векторизованным NumPy без циклов по пикселям, а каждое утверждение из теории проверено численно тестами. Исходные решения при этом оказались не безошибочными, и об этом ниже написано прямо.

## Множество Мандельброта и два свойства

Для $c \in \mathbb{C}$ рассмотрим орбиту нуля: $z_0 = 0$, $z_{n+1} = z_n^2 + c$. Множество Мандельброта $M$ состоит из тех $c$, для которых орбита ограничена.

**Свойство 1. $M$ симметрично относительно вещественной оси.**

Обозначим $z_n(c)$ члены орбиты. Покажем по индукции, что $z_n(\bar c) = \overline{z_n(c)}$. База: $z_0 = 0 = \bar 0$. Шаг: сопряжение согласовано со сложением и умножением, поэтому
$$z_{n+1}(\bar c) = z_n(\bar c)^2 + \bar c = \overline{z_n(c)}^{\,2} + \bar c = \overline{z_n(c)^2 + c} = \overline{z_{n+1}(c)}.$$
Модули орбит совпадают, значит, одна ограничена тогда и только тогда, когда ограничена другая, и $c \in M \iff \bar c \in M$.

**Свойство 2. Если $|c| \gt 2$, то $c \notin M$.**

Положим $|c| = 2 + \delta$, $\delta \gt 0$. Докажем по индукции, что $|z_n| \ge |c|\,(1+\delta)^{n-1}$ при $n \ge 1$. База: $z_1 = c$. Шаг: пусть $|z_n| \ge |c|$. Тогда
$$|z_{n+1}| \ge |z_n|^2 - |c| \ge |z_n|^2 - |z_n| = |z_n|\,(|z_n| - 1) \ge |z_n|\,(|c| - 1) = |z_n|\,(1 + \delta).$$
Орбита растёт не медленнее геометрической прогрессии и уходит на бесконечность, значит, $c \notin M$.

Из этого следует вывод, который использует код: достаточно ждать, пока $|z_n|$ превысит 2.

**Лемма (почему радиус выхода равен 2).** Если $|c| \le 2$ и $|z_n| = 2 + \varepsilon$ для некоторого $\varepsilon \gt 0$, то орбита уходит на бесконечность: $|z_{n+1}| \ge (2+\varepsilon)^2 - 2 = 2 + 4\varepsilon + \varepsilon^2 \ge 2 + 4\varepsilon$, то есть превышение над двойкой растёт минимум в четыре раза за шаг.

</p>

Слева орбиты $c$ и $\bar c$ зеркальны. В центре все точки множества лежат внутри круга $|c| \le 2$, граница касается его в точке $-2$. Справа настоящий рост $|z_n|$ при $|c| \gt 2$ и нижняя оценка из доказательства, пунктиром.

Обе формулировки проверяются тестами на случайных точках: орбиты сопряжённых совпадают с точностью $10^{-12}$, симметрия найденного множества на сетке точная, оценка из доказательства выполняется для сотен случайных $c$ (`tests/test_properties.py`).

## Как это считается

Классическая реализация проходит по пикселям двойным циклом на чистом Python и для картинки 800 на 800 при 256 итерациях делает десятки миллионов шагов интерпретатора. Здесь картинка считается массивами целиком, а три приёма не дают вычислениям раздуться.

1. **Уплотнение активных точек.** Пиксели, которые уже ушли на бесконечность, исключаются из массива. С каждой итерацией работы становится меньше.
2. **Аналитическое отсечение.** Точки главной кардиоиды и луковицы периода 2 лежат в $M$ заведомо, поэтому они вообще не итерируются:
   $$q = (x - \tfrac14)^2 + y^2,\quad q\,(q + x - \tfrac14) \le \tfrac14 y^2 \quad\text{или}\quad (x+1)^2 + y^2 \le \tfrac1{16}.$$
3. **Блоки строк.** Картинка считается порциями, поэтому память не зависит от разрешения, а сглаживание делается суперсэмплингом $2 \times 2$.

За один проход собираются все величины, нужные раскраскам:

| Величина | Формула | Для чего |
|---|---|---|
| Номер выхода $n$ | первый $n$, при котором $\lvert z_n \rvert \gt B$ | классические полосы |
| Гладкое число итераций | $\mu = n + 1 - \log_2 \dfrac{\ln \lvert z_n \rvert}{\ln B}$ | раскраска без полос |
| Оценка расстояния | $d \approx \dfrac{\lvert z \rvert \ln \lvert z \rvert}{\lvert z' \rvert}$, где $z'_{n+1} = 2 z_n z'_n + 1$ | нити границы |
| Stripe average | среднее $\tfrac12 + \tfrac12 \sin(s \arg z_k)$ | узоры по углу орбиты |
| Ловушка орбит | $\min_k \lvert z_k - p \rvert$ | цветные пузыри вокруг точки $p$ |
| Угол выхода | $\arg z_n$ | бинарное разложение, внешний угол |

Для гладкой раскраски радиус выхода $B$ берётся большим (по умолчанию 256), для классических полос хватает 2. Типичные времена на двух ядрах обычного облачного контейнера: окно 1200 на 800 при 1000 итерациях считается около секунды, картинка 3600 на 2400 при 1500 итерациях около 16 секунд.

## Множества Жюлиа

Заполненное множество Жюлиа для параметра $c$ состоит из тех $z_0$, для которых орбита $z_{n+1} = z_n^2 + c$ ограничена. Связность определяется положением $c$: для $c \in M$ множество связно, для $c \notin M$ оно рассыпается в «пыль». Тест проверяет оба предельных случая: при $c = 0$ получается единичный круг, при $c = 1$ почти ничего не остаётся.

## Бассейны Ньютона

Метод Ньютона $z \mapsto z - f(z)/f'(z)$ из каждой точки плоскости сходится к одному из корней, и окраска по номеру корня даёт фрактал. Для многочлена с известными корнями $r_k$ шаг считается без раскрытия многочлена:
$$\frac{f(z)}{f'(z)} = \Bigl(\sum_k \frac{1}{z - r_k}\Bigr)^{-1}.$$
Так нет переполнений при больших $|z|$, а точка, попавшая ровно в корень, обрабатывается отдельно (шаг Ньютона там делил бы на ноль).

<p align="center">
  <img src="assets/newton-basins.jpg?v=1" alt="Бассейны Ньютона для z^3 - 1, z^5 - 1 и z^3 - 2z + 2" width="100%">
</p>

Слева $z^3 - 1$, в центре $z^5 - 1$. Справа $z^3 - 2z + 2$: у метода Ньютона для него есть притягивающий цикл $\{0, 1\}$, поэтому часть плоскости не сходится ни к одному корню, это тёмные диски на границе бассейнов. Яркость показывает скорость сходимости: у корней светло, у границ темно.

Тесты проверяют, что три бассейна для $z^3 - 1$ имеют равные площади, что картина симметрична относительно вещественной оси (два комплексных корня меняются местами), и что у $z^3 - 2z + 2$ есть несошедшиеся точки.

## Конформные отображения

Исходная область $F$ это верхняя полуплоскость без отрезка $[0, i]$. Нужно перевести её конформно и взаимно однозначно в две разные области.

**Вариант A.** $G = \{\mathrm{Im}\,w \gt 0,\ |w| \gt 1\}$, верхняя полуплоскость без единичного полукруга.

**Вариант B.** $G = \{0 \lt \mathrm{Im}\,w \lt \pi,\ \mathrm{Re}\,w \gt 0\}$, полуполоса.

Цепочка общая, вариант B продолжает вариант A ещё одним шагом:

1. $w = z^2$ переводит $F$ в плоскость без луча $[-1, +\infty)$: полуплоскость раскрывается, а отрезок $[0, i]$ превращается в $[-1, 0]$.
2. $w = w + 1$ сдвигает разрез в $[0, +\infty)$.
3. $w = i\sqrt{-w}$ переводит $\mathbb{C} \setminus [0, +\infty)$ в верхнюю полуплоскость. Главная ветвь корня применяется к $-w$, поэтому её разрез совпадает с разрезом самой области и внутри области отображение непрерывно.
4. $w = J^{-1}(w)$, обратная функция Жуковского $J(w) = \tfrac12 (w + 1/w)$. Из двух корней $w + 1/w = 2\zeta$ выбирается тот, у которого $|w| \gt 1$. Это вариант A.
5. $w = \ln w$ переводит $\{\mathrm{Im}\,w \gt 0,\ |w| \gt 1\}$ в полуполосу. Это вариант B. Заодно $\ln J^{-1}(\zeta) = \mathrm{arccosh}\,\zeta$.

Итоговые формулы:
$$g_A(z) = J^{-1}\!\left(i\sqrt{-(z^2+1)}\right),\qquad f_A(w) = i\sqrt{1 - \Bigl(\tfrac{w + 1/w}{2}\Bigr)^2},$$
$$g_B(z) = \mathrm{arccosh}\!\left(i\sqrt{-(z^2+1)}\right),\qquad f_B(w) = i\sqrt{1 - \cosh^2 w}.$$

На картинках каждая точка области окрашена по своему положению в итоговой области и сохраняет цвет на каждом шаге, а линии сетки видны как ортогональные кривые: это и есть конформность. Цветные кривые это границы: голубая и оранжевая образуют вещественную ось, розовая и зелёная берега разреза. Видно, как берега разреза в конце оказываются на единичной полуокружности (вариант A) и на мнимой оси полосы (вариант B).

## Что исправлено по сравнению с исходными решениями

Исходные решения строили картинки, но численная проверка показала в формулах три дефекта.

| Что было | В чём проблема | Как стало |
|---|---|---|
| Вариант A: $g(z) = i\sqrt{\bigl(\tfrac{z+i}{z-i}\bigr)^2}$ | Главное значение корня из квадрата равно $\pm$ подкоренного выражения, поэтому отображение двулистное: две разные точки области имеют один образ. Тест подбирает такие пары. Из-за свёртки образ всегда лежал в $G$, и ошибка была незаметна на картинке. | Цепочка из четырёх обратимых шагов, инъективность проверена |
| Вариант B: $\sqrt{z^2+1}$ главной ветви | Разрез главной ветви лежит на луче $\{it,\ t \gt 1\}$, то есть внутри области. Через этот луч образ скачет ровно на $\pi$ (от нижней границы полосы к верхней), это и были белые «клинья» на исходных рисунках. | Корень применяется к $-(z^2+1)$, разрез ветви совпадает с разрезом области |
| Вариант B: обратное $f(w) = i\sqrt{\cosh^2 w - 1}$ | Знак перепутан: из $\cosh w = i\sqrt{z^2+1}$ следует $z^2 = -\cosh^2 w - 1$. Исходная формула не возвращает ни одной точки области. | $f_B(w) = i\sqrt{1 - \cosh^2 w}$, проверено кругом туда и обратно |

Дефекты исходных формул закреплены тестами в `tests/test_original_formulas.py`, чтобы вывод не потерялся.

Прочие изменения по сравнению с исходными программами:

| Было | Стало |
|---|---|
| Код Мандельброта строил `np.bool` (удалён из NumPy) и работал только как скрипт | пакет с командной строкой, современный NumPy |
| Жюлиа считался тройным циклом на Python | тот же векторизованный движок, что у Мандельброта |

## Как запустить

```bash
pip install -e ".[dev,pdf]"

# любое окно множества Мандельброта, любая раскраска
complexplane mandelbrot --center=-0.7436448+0.1318253j --width 0.0035 --iters 2500 \
    --palette ice --mode shaded --size 1600 --out out/seahorse.jpg

# множество Жюлиа для заданного c
complexplane julia --c=-0.5251993+0.5251993j --palette neon --out out/julia.jpg

# бассейны Ньютона для z^n = 1
complexplane newton --degree 5 --out out/newton5.jpg

# конформные отображения по шагам
complexplane conformal a --out out
complexplane conformal b --out out

# все иллюстрации этого README и PDF со всеми раскрасками
complexplane figures --out assets
complexplane gallery --out docs/mandelbrot-colorings.pdf
```

Способы раскраски: `smooth`, `classic`, `histogram`, `distance`, `stripes`, `trap`, `shaded`, `binary`, `radiance`. Палитра это имя из проекта (`fire`, `ice`, `aurora`, `sunset`, `neon`, `gold`, `ocean`, `candy`, `ultraviolet`, `ember`, `emerald`, `paper`, `rainbow`, `magenta-teal`, `warm-cool`, `deep-sea`) или любая карта matplotlib. Параметр `--center` с отрицательным числом пишется через знак равенства.

## Ограничения

- Расчёт в двойной точности (`float64`): окна уже примерно $10^{-13}$ превращаются в пиксельную кашу. Для более глубокого увеличения нужна арифметика с повышенной точностью и теория возмущений.
- Всё считается на CPU средствами NumPy. Для картин порядка 4K с тысячами итераций это десятки секунд, для видео с зумом нужен компилятор (Numba, C) или видеокарта.
- Конформные отображения проверены на выборках точек и на границах, а не доказаны строго для каждой стадии в тексте. Доказательства для свойств множества Мандельброта выше полные.
