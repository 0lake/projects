# Данные

Датасет не включён в репозиторий. Скачайте его с Kaggle: https://www.kaggle.com/datasets/tommasofacchin/resident-evil/data

Положите в эту папку файлы:

- `games.csv`
- `characters.csv`
- `gameAppearance.csv`
- `scenes.csv`
- `interactions.csv`

Скрипт `analysis/01_build_network.R` создаст здесь промежуточные `.rds` и `.csv`; они игнорируются git.
